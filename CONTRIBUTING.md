# Contributing

Small, focused changes are welcome. Please keep scripts readable and use a clear commit message for each contribution.

## Before opening a change

1. Run the automated tests with `python -m unittest -v` from the repository root.
2. For changes to the interactive demo, run `python main.py` and try representative inputs, including edge cases such as a zero denominator.
3. Update the README when commands or user-facing behavior change.
4. Keep each change focused so it is easy to review.
